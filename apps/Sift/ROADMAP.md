# Sift native roadmap

WinUI 3 is the sole Sift client. This ledger tracks feature completion without keeping a compatibility UI alive.

| Area | Current state | Next completion gate |
|---|---|---|
| Core execution and permissions | Typed atomic backup, target policy, crash-aware recovery, non-abandonable confirmed mutations, signed request/helper leases, administrator-side operation consent, pinned Windows tools, and deterministic tests | Expand deterministic tests with every newly exposed action |
| Shell and navigation | Fourteen native routes, stretched workspaces, DPI-aware 1100×720 minimum, responsive console overlay, keyboard routing | Complete the remaining accessibility audit |
| Activity console | Search, severity filter, copy, clear, bounded follow mode | Optional file export and direct resize grip |
| Home | Six/four/two-column customizable profiles; drag, keyboard move/resize, hide/duplicate/reset, undo/redo, import/export, typed live widgets, 90-day local trends, alerts, guarded Optimize/Maintenance/process/service actions, and workspace deep links | Expand native UI automation to every resize combination and add optional profile sync only after defining encryption, conflict, and privacy contracts |
| Optimize | Selection, filters, presets, checked confirmation, current-user changes, scoped administrator permission, and a backup link that opens Recovery | Finish typed result-to-copy mapping and resource extraction |
| Task Manager | Typed collapsible process/service/task tables, policy labels, filtering, exact single-process End/Restart with live path revalidation, and exact third-party service Start/Restart through bounded one-shot elevation | Add process-tree grouping and export; keep bulk mutation out until per-target review UX is defined |
| Performance | LiveCharts2 vertical slice; workspace-scoped PDH CPU/disk; Battery Saver cadence floor | Persist chart controls and add process click-through |
| Hardware Monitor | LibreHardwareMonitor inventory, summaries, filters, collapsible device groups, min/max readings, selected-sensor LiveCharts2 history, and active-workspace-only pause/refresh lifecycle | Add persisted favorites/alerts and optional signed provider plugins after defining a trust and compatibility contract |
| Startup | Sortable startup inventory, search, refresh, status, and Windows Startup Settings link | Automated narrow-layout and accessibility verification |
| Maintenance | Categorized selection, confirmed cleanup, one-use reviewed-content tickets, execution-time drift rejection, path policy, registration backup, and administrator-session-only machine registrations | Visible scan progress/cancel and cleanup history |

| Health | Read-only checks plus local activity and recovery history | Deep links and persisted diagnostic history |

| System Information | Typed read-only 10-category inventory, summary cards, search/category filters, full-value inspector, privacy-aware copy, optional-provider warnings, progress/cancel lifecycle, and msinfo32 handoff | Add signed JSON export and monitor EDID decoding after a privacy/schema review |
| Settings and dialogs | CommunityToolkit SettingsExpander/SettingsCard for shell, lifecycle monitor, performance, restore-point, and reset preferences; guarded action dialogs | Windows permission-cancellation dialog automation coverage; optional verbose-log toggle in UI (env `SIFT_LOG_VERBOSE` works today) |
| Core libraries | CsWin32 interop, Humanizer/`SiftDisplay`, `SiftResult`, local Serilog, PDH sampler, BatteryReportReader, BenchmarkDotNet harness | Wave 3 optional Spectre/ETW/Appx; keep measuring before new telemetry sources |

## Completion rule

A workspace is complete only when its applicable normal, empty, loading, filtered, error, confirmation, cancellation, narrow, and accessibility states are implemented and visually verified. Actions that change Windows or remove data must also prove non-mutating inspection, confirmation cancellation, backup-first execution where supported, rollback behavior, execution-time revalidation, and Core policy enforcement.
