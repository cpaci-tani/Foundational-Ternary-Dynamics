**N is the compositum of two components, N := ⟨N_calc, N_dyn⟩ (smallest subfield of ℝ containing both).**

### §1.2 N_dyn — the dynamical component (the new definitional content)

N_dyn is the subfield of ℝ generated by all limits x = lim_{j→∞} a_{L_j} of **admissible native schemas**, where an admissible schema is a family (a_L) satisfying all four clauses:

- **(D1 — uniformity.)** One finite, L-independent description generates a_L at every lattice size L in a fixed arithmetic ladder (all L, or a fixed congruence class such as odd L — the ladder is part of the finite description). The description names: the observable, the source configuration, and the horizon rule. *No L-dependent tables, no L-indexed case lists.*
- **(D2 — linear sector.)** a_L is an observable of the substrate's **linear sector**: finite compositions of the rules-1/2/3/5 linear machinery (wave updates, gradients/curls, exact Gauss/Poisson solves) evaluated at finite horizon — the Lemma-0 rational-linear class. Threshold/nonlinear rules (rule 4, rule 6's collision, the default-ON toggles' gates) are **excluded from v1** (see §3.3).
- **(D3 — canonical sources.)** Initial/source data is the vacuum plus a finite, fixed-description source pattern with entries in ℚ (e.g., a unit charge at the origin; a fixed finite dipole). The pattern's description is L-independent (D1).
- **(D4 — polynomial modulus.)** The limit exists with a polynomial convergence modulus: ∃ rational C, θ > 0 with |a_L − x| ≤ C·L^{−θ} along the ladder.

By Lemma 0 (`FOUND_FINITE_HORIZON_ALGEBRAICITY.md`), every a_L is an **algebraic number**; N_dyn's transcendental content, if any, enters exclusively at the D4 limit. N_dyn is a countable field (countably many finite descriptions; field closure preserved by combining schemas).

**Parameter policy (from Lemma 0):** coupling symbols are indeterminates natively; a schema may use only ℚ-assigned parameters in its description. Assigning a transcendental value to a coupling is an import and is **outside N by definition** — that is not tuning; it is the program's subject matter (the parameter-assignment door of Corollary 2).

## §3 — Properness (the definition excludes something, and the risks are named)

- **§3.1 Countability.** N is countable; almost every real is outside it. (Formal properness.)
- **§3.2 Linear-sector tameness.** D2 confines schemas to rational-linear solves and finite linear compositions: outputs are values of L-indexed rational-linear functionals of fixed rational sources. No embedded computation is available in this sector (linear dynamics cannot implement branching logic), so the schema class cannot smuggle arbitrary computable reals via initial-data engineering. This is the structural properness argument, and it is why D2 exists.
- **§3.3 The named deferral.** For the full nonlinear substrate (rule 4 thresholds, collisions, default-ON gates), tameness of the analogous closure is **not established** — a Turing-completeness-style embedding is not excluded, and with it properness could fail. v1 therefore *deliberately* covers the linear sector only; the nonlinear rung is future work behind a v2 pre-registration. This deferral is a scope statement, not a concession on δ-IND: every documented dynamical inventory row is linear-sector.
- **§3.4 What properness does NOT presuppose.** Nothing in §3 asserts δ ∉ N — that is S3's question, untested at lock, on pain of B1.
