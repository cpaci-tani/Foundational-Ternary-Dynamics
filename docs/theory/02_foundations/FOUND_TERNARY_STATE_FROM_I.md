## 3 · Why `s = i²` rather than `s = i`?

The state field carries **discrete polarity / cardinality** content. Continuous phase information lives in the flux field `J ∈ ℝ³`. The choice `s = i²` (rather than `s = i`) reflects this division of structural labor:

- `i` itself encodes a 90° phase rotation — continuous angular content. This naturally inhabits the flux field `J`, which carries vector/directional content.
- `i² = −1` is purely real and discrete-valued. It carries discrete polarity with no residual phase. This naturally inhabits the discrete state field.

So `s = i²` correctly captures that the state field is the **phase-collapsed real projection** of the imaginary axis. The full `Z[i]` content (with continuous phase) is distributed across the two-layer ontology:

- `s` (state field) carries the **discrete real-phase-collapsed** content — `s ∈ {i², 0, |i²|} = {−1, 0, +1}`.
- `J` (flux field) carries the **continuous vector / phase-bearing** content — magnitude `|J|` is the "infinite potential" each voxel can carry.

This is consistent with `SPEC_FTD.md` §1.1's existing graded-monism reading and with `REF_REFLEXIVITY_VOCABULARY.md`'s dispositional/actual split.
