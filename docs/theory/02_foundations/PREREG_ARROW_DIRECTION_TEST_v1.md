## 0 · The question

FTD-0314/0315 decomposed time's arrow into *existence* (downstream of the i-act, `[THEOREM]` operator content), *identification with physical time* (FC-2 declaration), and *direction* (which way is "forward"), and tagged the **direction a free orientation act** (`±ω`, a residual `ℤ/2`). This test asks: is the direction **forced**, **imposed** (a boundary condition), or genuinely **free**? Phase-1 exploration found canon contradicts itself (FTD-0314/0315 "free"; `FOUND_META_PATTERNS.md` §0.5.4 "low-entropy initial conditions"; FC-2 "native"), so the test must also **reconcile** and (per owner decision) **correct** the wrong docs.

The lens: *an act of intent = a `√` = an unforced `ℤ/2`-break.* If "backward" is not a defined dynamics, there is no `ℤ/2` and hence no act — the direction would be **forced**, not a free orientation.

## 1 · The direction-taxonomy (locked categories)

The direction of a given arrow is assigned **exactly one**:
1. **forced-structural** — fixed by P1–P5 alone (independent of FC-2). [Note: FTD-0253 already proves P1–P5 are reversibility-silent, so this category is expected empty.]
2. **forced-given-FC-2** — fixed once FC-2 commits the irreversible/manifestation sector as fundamental: the update map is then many-to-one, has no inverse, so "backward" is not a defined dynamics (no `ℤ/2` to choose).
3. **imposed** — set by a low-entropy boundary/initial condition (Past Hypothesis), not derivable from the dynamics.
4. **free orientation** — both directions defined and admissible, no preference (the current FTD-0314/0315 claim).

## 2 · The three objects to keep distinct (the reconciliation hypothesis)

The test must assign each canonical claim to the object it actually concerns; conflating them is the suspected source of the contradiction:
- **substrate/causal arrow** — the direction the update map runs.
- **thermodynamic arrow** — the direction/existence of entropy increase.
- **reversible-wave `±ω` orientation** — a `ℤ/2` in the *reversible flux/wave* sector, which carries **no** arrow.

## 4 · Admissible verdicts (mechanical, layered allowed)

A **layered** verdict is admissible: assign a category (§1) to each object (§2). Mechanical criteria:
- **forced-given-FC-2** for an object iff a mechanism (§3) makes one direction the only *defined* (a: no inverse) or the only *well-posed* (c) direction, conditional on FC-2.
- **imposed** iff the object's asymmetry requires a low-entropy boundary not derivable from dynamics.
- **free orientation** iff both directions are defined, well-posed, and admissible with no preference.

**Prior-favoured outcome (disclosed, not pre-decided):** substrate/causal arrow **forced-given-FC-2** (mechanism a, reinforced by b, c); thermodynamic arrow's *gradient* **imposed** (low-entropy past) but its *direction* = the causal one; reversible-wave `±ω` **free but arrow-less**. ⇒ FTD-0314/0315's "free orientation" is a mislabel (it pointed at the wave sector); FOUND_META_PATTERNS §0.5.4's aside is rescoped to the thermodynamic arrow.
