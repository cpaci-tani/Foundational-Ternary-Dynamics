# Foundation: Minimal Instantiated Universe

**Date:** 2026-04-24
**Status:** [FOUNDATION] / [SELECTION]
**Purpose:** List the minimum ingredients required for an instantiated universe,
starting from distinguishability and building only as much structure as each
stage logically requires.

---

## 0. Guiding Distinction

This document separates five layers:

```text
existence       something is distinguishable from nothing
context         a frame/interface in which distinction is instantiated
relation        at least two distinguishables can be compared
change          relations differ across ordered observations
physics         stable rules govern allowed changes
```

A single voxel can exist without requiring a grid, orientation, velocity, or
time. Those structures become necessary only when relation, change, and rule
closure enter.

However, "existence" is not operationally complete without a context
instantiator. The context instantiator is the frame, interface, or subsystem
relative to which contrast is registered. It may be external to the universe
being described, internal to it, or distributed across its relations.

## 2. Ingredient One: Context Instantiator

**Tag:** [AXIOM] / [FOUNDATIONAL SELECTION]

Minimum requirement:

```text

```

The context instantiator is not necessarily a conscious observer. It is the
minimal frame/interface that makes the statement:

```text

```

well-formed.

Possible forms:

```text

internal subsystem
boundary condition
recording interface
relational network of multiple units
```

Why it is required:

```text

with context, the unit becomes instantiated as a contrast
```

What it does not yet require:

```text
time
metric space
consciousness
many-body dynamics
```

In later many-body systems, the context instantiator may become endogenous:
the universe can instantiate context for itself through persistent records,
subsystems, and relational closure.

The ingredient stack can be expressed as a constructor. The constructor is not
a software API yet; it is the logical signature for what must be declared before
a universe, subsystem, or EFT bridge is well-formed.

### Constructor Signature

```text
construct_universe(
    required: RequiredInstantiation,
    optional: OptionalPhysics = {}
) -> InstantiatedUniverse
```

### Required Parameters

These are required for an instantiated universe in the strict sense.

```text
RequiredInstantiation {
    context_contrast: ContextContrast,
    ontic_units: NonEmptySet[OnticUnit],
    individuation: IndividuationRule,
    closure: ClosureCondition,
    admissibility: LawAdmissibilityCriteria
}
```

Meaning:

```text
context_contrast
    paired declaration that contrast is registered in a context

individuation
    criterion for when a unit, record, or flow is counted as persistent

closure
    declaration of what is inside, outside, boundary, or self-contextual

admissibility
    filters separating candidate physics from arbitrary computation
```

Minimal validation:

```text
context_contrast.context is defined
context_contrast.contrast is defined
ontic_units.count >= 1
individuation is compatible with ontic_units
closure defines the accounting domain
admissibility is declared before update rules are accepted as physics
```
