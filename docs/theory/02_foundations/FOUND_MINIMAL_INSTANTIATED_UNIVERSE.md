# Foundation: Minimal Instantiated Universe

**Date:** 2026-04-24
**Status:** [FOUNDATION] / [SELECTION]
**Purpose:** List the minimum ingredients required for an instantiated universe,
starting from distinguishability and building only as much structure as each
stage logically requires.

---

## 0. Guiding Distinction

This document separates five layers:

```text
existence       something is distinguishable from nothing
context         a frame/interface in which distinction is instantiated
relation        at least two distinguishables can be compared
change          relations differ across ordered observations
physics         stable rules govern allowed changes
```

A single voxel can exist without requiring a grid, orientation, velocity, or
time. Those structures become necessary only when relation, change, and rule
closure enter.

However, "existence" is not operationally complete without a context
instantiator. The context instantiator is the frame, interface, or subsystem
relative to which contrast is registered. It may be external to the universe
being described, internal to it, or distributed across its relations.

## 2. Ingredient One: Context Instantiator

**Tag:** [AXIOM] / [FOUNDATIONAL SELECTION]

Minimum requirement:

```text
there is a context in which distinction can be instantiated
```

The context instantiator is not necessarily a conscious observer. It is the
minimal frame/interface that makes the statement:

```text
this is distinguishable from not-this
```

well-formed.

Possible forms:

```text
external observer frame
internal subsystem
boundary condition
recording interface
relational network of multiple units
```

Why it is required:

```text
without context, "one unit" is only an ungrounded assertion
with context, the unit becomes instantiated as a contrast
```

What it does not yet require:

```text
time
metric space
consciousness
many-body dynamics
```

In later many-body systems, the context instantiator may become endogenous:
the universe can instantiate context for itself through persistent records,
subsystems, and relational closure.

## 17. Ingredient Sixteen: Context-Contrast Co-Primitivity

**Tag:** [FOUNDATIONAL SELECTION]

The first two ingredients should be read as a paired foundation, not as a
strict temporal sequence.

Primitive statement:

```text
instantiation = contrast + context-of-registration
```

Contrast without context is not operationally grounded:

```text
"something" cannot be distinguished from "nothing" without a registration frame
```

Context without contrast is empty:

```text
a frame that registers no distinction has no instantiated content
```

Therefore the minimal base is:

```text
not void alone
not observer alone
but distinguishability-in-context
```

This keeps the one-voxel analogy honest. A single white voxel in infinite black
space is not yet a physical universe unless the contrast is instantiated in a
context where "white rather than black" is a meaningful distinction.

## 18. Ingredient Seventeen: Individuation / Persistence

**Tag:** [SELECTION]

If an ontic unit is discussed across labels, frames, or ticks, the theory needs
a rule for individuation.

Minimum requirement:

```text
there is a criterion for when a unit is "the same" unit
```

Possible criteria:

```text
same occupied site at one tick
continuous transport path across ticks
conserved signed charge
persistent record label
worldline segment in the history ledger
```

Why it matters:

```text
without individuation, movement is only relabeling
without persistence, memory has no subject
without identity criteria, conservation cannot be assigned to carriers
```

FTD engine correlate:

```text
state occupancy       instantaneous manifestation
transport ledger      continuity of movement
reaction ledger       local identity break/change
history blocking      coarse persistent identity
```

This does not require a permanent particle substance. It only requires a
well-defined criterion for tracking continuity when continuity is claimed.

## 19. Ingredient Eighteen: Frame / Gauge Redundancy

```text

```

Intrinsic dynamics require:

```text
relations among instantiated units change
or internal state/flux changes
or records differ across ordered observations
```

Therefore the primitive split is:

```text
gauge/frame relabeling     not physical motion
relational change          candidate physical motion
ledgered state change      physical dynamics
```

This protects the two-voxel argument:

```text
two static voxels viewed from another angle do not move internally
two voxels changing relation inside the system instantiate dynamics
```

FTD engine correlate:

```text
coordinate choice is descriptive
local neighborhood relation is operative
conservation ledgers track intrinsic updates
```
