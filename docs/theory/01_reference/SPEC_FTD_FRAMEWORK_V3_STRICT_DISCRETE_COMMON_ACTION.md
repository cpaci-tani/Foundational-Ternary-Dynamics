## 2. P2 — global ordinal clock and temporal existence `[AXIOM]`

### Statement

The substrate has one global succession

\[
 n\in\mathbb N_0,
\]

with a first tick `n=0` and no postulated final tick. Every physical record
`r` has a birth tick `b(r)`. Its expiry tick `e(r)` is either a realized later
tick or remains undefined (`perp`) while the record persists:

\[
 r\text{ exists at }n
 \iff b(r)\le n\ \text{and}\
 \bigl(e(r)=\perp\ \text{or}\ n<e(r)\bigr).
\]

No physical instantiation is timeless. An undefined future endpoint is not a
completed infinity and is not a second time coordinate.

`N_0` here denotes the successor rule and the arbitrarily extendable realized
finite prefix of ticks; it does not assert a completed future history.

### Global time versus local clocks

The global tick never dilates. A local clock is a recurrent material process
that completes some number of internal cycles during a number of global ticks.
Local clock-rate differences must therefore arise from the local transaction
history—admission, stalling, loading, interaction, or an equivalent mechanism.

The global tick is not multiplication by a root of unity on the ternary
values. In particular, multiplication by `exp(2 pi i/3)` fixes `0` and does not
implement the permutation `-1 -> 0 -> +1 -> -1`. A C3 or C4 finite phase cycle
may be a local clock realized by `Phi`; it is not P2 itself.

### Consequences and non-consequences

- Substrate simultaneity and update order are absolute.
- A preferred global description exists, while internal observers access only
  local records.
- P2 does not derive an oscillator, proper time, the Lorentz factor, a
  tick-to-second conversion, or the speed of light.
- Seconds are an operational calibration of material clocks. Their appearance
  in the measured units of `c` is not by itself a proof of P2.
