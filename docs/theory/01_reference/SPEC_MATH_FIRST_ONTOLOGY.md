## 0. Purpose

This document states FTD's math-first ontology:

> **Ontology = finite mathematical invariant structure.**
> **Physics = operationally stable readout of that structure.**

The goal is to prevent two equal and opposite errors:

1. Treating mathematical coincidences as physical derivations.
2. Treating physical entities as primitive when FTD intends them to emerge as readouts.

This is a discipline document. It does not add a new axiom, theorem, particle, field, or coupling.

---

## 1. Core Thesis

FTD should be read in four layers:

```
Mathematical primitive
  -> invariant structure
  -> admissible readout
  -> operational physics
```

Physical language enters only at the fourth layer.

Consequences:

- A number is not a constant of nature until a readout rule says what measurement accesses it.
- A field is not automatically a physical field until an operational observable is defined.
- A particle is not primitive; it is a stable manifestation/readout category.
- A coupling is not derived by finding a matching number; it is derived only when a measurement functional returns that number without using the target as input.

This is the ontology behind `SPEC_ALPHA_READOUT_CONTRACT.md`.

## 4. Layer M2: Admissible Readout

The readout layer decides which mathematical invariants become publicly measurable.

A readout map has the shape:

```
R_phys : (preparation, observable algebra, invariant) -> measured dimensionless quantity
```

For a readout to be admissible, it must be:

- **Finite-block definable:** no completed-infinity dependence.
- **Symmetry-compatible:** respects translation, cubic/O_h symmetry, and relevant gauge redundancies.
- **Operational:** tied to a measurement protocol, not just a named number.
- **Stable:** robust under preparation, lattice size, and harmless gauge/calibration changes.
- **Non-circular:** target value is not an input.
- **Layer-honest:** does not import standard QFT/SM formulae and relabel them as substrate derivations.

`SPEC_ALPHA_READOUT_CONTRACT.md` is the alpha-sector specialization of this layer.

## 5. Layer M3: Operational Physics

Physics begins when an admissible readout is connected to an experiment or engine-measurable protocol.

| Physics category | Math-first reading |
|---|---|
| Charge | Readout of signed manifestation / flux-divergence structure |
| Mass | Readout of stable cluster or invariant functional, calibration-conditional |
| Coupling | Readout of interaction strength under a declared measurement functional |
| Particle | Persistent finite pattern under dynamics and readout |
| Field | Effective coarse observable over substrate histories |
| Spacetime | Effective ordering / metric readout from adjacency and propagation constraints |
| Gauge symmetry | Redundancy of representation preserving admissible observables |

The physics layer is real if the readout is real. It is not primitive.

## 6. The Manifestation Principle

FTD's two-layer ontology should be read as:

```
Dispositional layer: flux / capacity / invariant structure
Manifest layer: state / event / public readout
```

The state field `s` is not a second substance. It is the actualized manifestation of the flux/substrate relation under the Genesis rule.

This supports graded monism:

- the void has dispositional content;
- manifestation is actualization of that content;
- measurement is public stabilization of a manifestation/readout;
- physics is the calculus of stable public readouts.

This does not solve the Born rule, consciousness, or reflexivity sectors. It only fixes the ontological ordering they must obey.

## 7. The Alpha Case

The master quadratic root `x_+` is currently:

- mathematically well-defined;
- structurally rigid within declared families;
- numerically close to physical `1/alpha`;
- not yet operationally derived.

Under math-first ontology, the right statement is:

> `x_+` is an invariant candidate for an electromagnetic readout.

The wrong statement is:

> `x_+` is the physical fine-structure constant because the number matches.

To upgrade the claim, FTD must supply an admissible readout map:

```
(charge-like preparation, observable algebra, EM measurement functional)
  -> inverse coupling
  -> x_+
```

This is exactly MC-T4.3 / ARC-B1.

## 8. Anti-Cheat Rules

The math-first ontology fails if it becomes a license to rename fits as reality.

Therefore:

- Do not call an invariant a physical observable without a readout map.
- Do not call a parametric insertion a derivation.
- Do not choose a readout after seeing the target.
- Do not hide standard physics inside the readout rule.
- Do not treat dimensional calibration as ontology.
- Do not promote reflexive/noetic language into a physics mechanism without an observable algebra.
- Do not add new physical sectors before their readout layer is explicit.

These are methodological constraints, not stylistic preferences.

## 9. Status Test For Any Claim

Every FTD claim should answer four questions:

| Question | If yes | If no |
|---|---|---|
| Is the mathematical object defined? | It can enter M0/M1. | It is not ready. |
| Is an invariant proved or measured? | It can be cited as math/engine content. | It remains conjectural. |
| Is a readout map specified? | It can enter M2. | It is not yet physics. |
| Is the readout operationally tied to measurement? | It can enter M3. | It remains structural interpretation. |

This table should be used before promoting any claim in the doctrine ledger.
