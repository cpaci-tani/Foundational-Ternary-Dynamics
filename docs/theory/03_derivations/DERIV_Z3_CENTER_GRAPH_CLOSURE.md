## §1 — Statement

### §1.1 Closure theorem

> For a system of `N` constituents with Z_3 color charges `c_1, …, c_N ∈ {0, 1, 2}` in the fundamental representation, the state lies in the Z_3-trivial (center-closed) subsector iff
>
>     ∑ c_i  ≡  0   (mod 3).                      (eq. 1)

`0` is the singlet, `1` is the quark `q`, `2` is the anti-quark `q̄` (= `−q` in Z_3 since `2 ≡ −1 mod 3`).

### §1.2 Projector identity

> The **center projector** onto the `c = 0` sub-space is
>
>     P_0  =  (1/3) · ( I + Z + Z² )               (eq. 2)
>
> with `Z = diag(1, ω, ω²)` and `ω = e^{2πi/3}`. In the fundamental rep this evaluates to `diag(1, 0, 0)`; it is idempotent (`P_0² = P_0`) and rank-1 (`tr(P_0) = 1`).

Both (eq. 1) and (eq. 2) are `[THEOREM]`.

---

## §2 — Setup

Z_3 is the cyclic group of order 3. The fundamental rep is one-dimensional per "color slot," generated by `ω = e^{2πi/3}`. A multi-quark state's color is the sum (mod 3) of its constituents' charges. The closure characterisation (eq. 1) just restates the standard fact that the Z_3-trivial subspace of a tensor product of fundamentals is the kernel of the action of the generator on the diagonal sum.

The cyclic-sum identity `1 + ω + ω² = 0` (Z_3 character orthogonality) is the load-bearing arithmetic fact.

---

## §3 — Proof

### §3.1 Closure (eq. 1)

A state `|c_1⟩ ⊗ … ⊗ |c_N⟩` carries total Z_3 charge `C ≡ ∑_i c_i (mod 3)`. The generator `Z` acts on a charge-`c` state as `ω^c`. By unique-factorisation of cyclic groups, the state is in the kernel of `(Z − I)` (i.e. fixed by the generator) iff `ω^C = 1` iff `C ≡ 0 (mod 3)`. ∎

### §3.2 Projector identity (eq. 2)

On a charge-`c` eigenstate, `Z` acts as `ω^c`, so `Z²` acts as `ω^{2c}`. Therefore

    P_0 |c⟩  =  (1/3) ( 1 + ω^c + ω^{2c} ) |c⟩.

Using the cyclic-sum identity `1 + ω + ω² = 0`:

| `c` | `1 + ω^c + ω^{2c}` | `P_0 |c⟩` |
|---|---|---|
| `0` | `1 + 1 + 1 = 3` | `|0⟩` |
| `1` | `1 + ω + ω² = 0` | `0` |
| `2` | `1 + ω² + ω = 0` | `0` |

So `P_0 = diag(1, 0, 0)` in the eigenbasis of `Z`. Direct multiplication gives `P_0² = P_0` (rank-1 idempotent), `tr(P_0) = 1`. ∎

### §3.3 Examples

| Configuration | Z_3 sum | Closed? |
|---|---|---|
| Meson `q + q̄`        | `1 + 2 = 3 ≡ 0` | ✓ |
| Baryon `q + q + q`     | `1+1+1 = 3 ≡ 0` | ✓ |
| Anti-baryon `q̄+q̄+q̄` | `2+2+2 = 6 ≡ 0` | ✓ |
| Tetraquark `qq q̄q̄`  | `1+1+2+2 = 6 ≡ 0` | ✓ |
| Pentaquark `qqqq q̄`  | `4 + 2 = 6 ≡ 0` | ✓ |
| Single quark `q`       | `1` | ✗ |
| Diquark `q + q`        | `1 + 1 = 2` | ✗ |
| Single antiquark `q̄`  | `2` | ✗ |
| `qq̄q`                | `1+2+1 = 4 ≡ 1` | ✗ |

Closure correctly recognises the observed SU(3)-color-singlet hadrons and correctly rejects the un-observed (confined) configurations.

## §5 — Open-flux penalty (`[CANDIDATE PRINCIPLE]`, **out of scope here**)

The closure theorem (eq. 1) says non-closed configurations are *forbidden* in the Z_3-trivial subsector — i.e., they live in the orthogonal complement of `P_0`. It does **not** say anything about the *energetic cost* of forbidding them.

A natural FTD-side conjecture is the **open-flux penalty**: non-center-closed configurations carry an energy `∝ (∑ c_i mod 3 ≠ 0)` (a confinement-style penalty). This would explain why isolated quarks are not observed as asymptotic states.

This is `[CANDIDATE PRINCIPLE]` — it has NOT been derived, NOT been tested in this module, and is recorded for honesty only. The LEDGER lists it as such. Promoting it to `[THEOREM]` would require deriving the energy functional from the substrate (e.g. via the Wilson-loop area-law route, FTD-0093 territory, or an explicit lattice action), which is separate work.

The theorem here does **not** newly derive SU(3) color, three colors, or confinement; it gives a clean primitive for working with the Z_3 *center* of an already-assumed SU(3) structure.
