# Audit — mobility convergence criterion

**Ledger ID:** FTD-0653  
**Status:** `[THEOREM — DIAGNOSTIC CORRECTION]`

The FTD-0652 minimum-mobility nondecrease gate is formally invalid as a general
continuum criterion. Explicit scalar counterexamples prove both directions:
`1+1/w` converges to one while decreasing, whereas `1/2-1/w` increases while
converging to the wrong target. Direction-dependent versions additionally show
that monotonicity does not enforce isotropy.

The correction is prospective. FTD-0652 remains mixed under its immutable
protocol. Future campaigns must separate:

- nonzero common mobility;
- direction independence;
- optional normalization to one;
- translation-reaction control;
- spectral pole identification.

This theorem changes no engine equation and promotes no matter claim.
