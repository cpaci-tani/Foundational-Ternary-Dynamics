## Result

The current frozen ternary-plus-real-field ontology has no localized protected
topological carrier. This remains true after fixing the ternary source, Gauss
law, and global harmonic flux: every nonempty continuous field fibre is an
affine subspace and contracts explicitly to any chosen base solution.

The conclusion also holds for finite but uncontained excitations on `Z^3` and
for finite-energy real fields. No boundary container or periodic-box artifact
is used in that part of the proof.

## What the result does not say

The ternary snapshot alphabet is discrete, but production reactions connect
its fibres. FTD-0421's rank-four/nullity-zero result excludes an invariant only
in its exact four-feature additive basis. This audit does not claim that every
possible transition-graph invariant is absent.

The static Derrick gate excludes a same-variable three-dimensional core built
only from nonnegative onsite and two-derivative energy. It does not exclude a
time-periodic nonlinear localized mode. Such a mode remains a genuine open
route, though FTD-0582 already excludes reciprocal backreaction from the frozen
production source graph.

## Consistency correction

FTD-0231-era statements that a ternary state or a `Z[i]^2` projection by itself
derives topological electric-charge quantization are false as written. A point
in a discrete alphabet is not a closed loop, bundle class, or invariant of the
production transition graph. The exact `C4` representation decomposition is
unaffected; the charge interpretation is reduced to a selected candidate
readout requiring an explicit loop construction and dynamical conservation.
