## 0. The choice (Route B over Route A)

**Target obstruction:** FTD-0208 proved the discrete substrate cannot derive the relativistic L² (Pythagorean) combination law. Route B's bet is that the **modular flow** of the right algebra *derives* it (via a Bisognano–Wichmann analog) rather than importing it.

## 1. The precondition is **type III₁** (not "modular flow exists")

Modular flow exists for any faithful state: on a type I factor with density matrix ρ, `σ_t = Ad(ρ^{it})`, generated by the modular Hamiltonian `K = −log ρ`. **But that is circular for *deriving* time** — the Hamiltonian is *inserted* by the choice of ρ, then "recovered" as the flow.

The decisive property is **canonicity**: for a **type III₁** factor the modular flow is **state-independent up to inner automorphisms** (Connes' classification; the flow of weights is an invariant). *Only then* is the emergent time **objective** — not "whatever dynamics we put in." So:

> **Route B requires the substrate's local algebra to be type III₁.** Type I / II / III_λ either give a circular (state-chosen) flow or a non-canonical one.

## 2. The viable route to III₁ — from the **IR**, not the UV

FTD's fundamental discreteness (lattice spacing ≡ ℓ_P; **no `ε → 0` continuum limit**, per the undefined-boundary ontology) does **not** block type III₁ — because the type need not come from the UV. An unbounded ternary+flux lattice **is** an infinite tensor product of finite type-I site algebras → an **Araki–Woods (ITPFI) factor**. Its type is fixed by the **Connes S-invariant = the asymptotic ratio set `r∞`** of the state's local spectra:

| asymptotic ratio set `r∞` (= Connes `S(M)`) | type |
|---|---|
| `{1}` | I or II (semifinite — circular/non-canonical flow) |
| `{0} ∪ {λⁿ : n ∈ ℤ}`, `0<λ<1` | III_λ (non-canonical flow) |
| `[0, ∞)` | **III₁ (canonical objective flow)** |

**A continuous ratio set `[0,∞)` ⇐ a continuous (gapless) mode spectrum.** A massless field has modes down to zero → continuous ratios → III₁. FTD's flux sector **is** massless — that is exactly **Phase-G geometric Coulomb** (`1/r`, long-range, gapless). So:

> **Masslessness is the engine.** FTD reaches III₁ from infinite extent + the gaplessness of the massless flux sector, *not* from removing the UV cutoff. The discreteness is fine.
