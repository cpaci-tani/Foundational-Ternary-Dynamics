## Solver status

The first dense implementation was computationally nonviable because it
rebuilt or solved a global `3N x 3N` Jacobian. A low-rank identity-Broyden
attempt completed but did not converge on the locked matrix. The final
instrument uses Jacobian-free Newton--Krylov directional evaluations of the
unchanged residual. No physical coefficient, arm, velocity, tolerance, or
verdict changed. Final accepted states satisfy the exact registered residual;
the solver is instrumentation, not a new interaction.

This distinction matters for future work. A local matter action should expose
its response as an operator, not require an ontic all-to-all matrix. The
matrix-free path makes the width-refined action executable, but a sparse/local
preconditioner is still needed before many-tick large-width campaigns are
practical.
