## 1. Arbitrary real base source

Let `a(n)` be any nonzero real source on an odd periodic `L^3` probe, with its
zero mode removed, and let

```text
A(k)=sum_n a(n) exp(-i k dot n).
```

Deposit every base coefficient through the FTD-0541 tensor quadratic coat and
translate the common coat phase by `f` along axis `i`. Linearity extends the
FTD-0553 calculation from signed ternary constituents to arbitrary real
coefficients. Write

```text
b(k)=(3+cos k)/4,
lambda(k)=2 sum_j (1-cos k_j),
Q(f)=f^4-f^2/2.
```

Then the exact finite-volume minimum-field energy is

```text
U_i(f)=U_0+C_i Q(f),                                      (1)

U_0=beta/(2L^3) sum_(k != 0)
    |A(k)|^2 prod_j b(k_j)^2/lambda(k),                   (2)

C_i=beta/(2L^3) sum_(k != 0)
    |A(k)|^2 (1-cos k_i)^2
    prod_(j != i)b(k_j)^2/lambda(k).                      (3)
```

Every summand is nonnegative. The half-cell barrier is

```text
Delta U_i=U_i(0)-U_i(1/2)=C_i/16.                        (4)
```

## 2. Exact spectral-index identity

Normalize the positive summands of (2):

```text
w(k)= [|A(k)|^2 prod_j b(k_j)^2/lambda(k)]
      /sum_[q != 0][|A(q)|^2 prod_j b(q_j)^2/lambda(q)].  (5)
```

Because `16 b(k_i)^2=(3+cos k_i)^2`, division of (3)--(4) by
(2) gives

```text
Pi_i[a] := Delta U_i/U_0
 = sum_(k != 0) w(k)
   ((1-cos k_i)/(3+cos k_i))^2.                          (6)
```

This is exact, not a fit or a small-momentum expansion. Since

```text
0 <= ((1-cos k)/(3+cos k))^2 <= 1,                       (7)
```

`0<=Pi_i<=1`. Equality `Pi_i=0` holds exactly when every energy-carrying mode
has `k_i=0`, which is the Fourier criterion for axis invariance. This recovers
FTD-0553's strict positivity for every localized nonzero source.

Equation (6) changes the physical reading. Spatial radius alone is not the
order parameter. `Pi_i` is the field-energy fraction weighted by a monotone
ultraviolet penalty. A large cloud that retains lattice-scale alternating
content can remain strongly pinned; a smooth low-momentum cloud can become
effectively unpinned.

## 3. Band-tail bound

Let `epsilon_i(kappa)` be the fraction of the normalized energy weight (5)
with `|k_i|>kappa`, for `0<=kappa<=pi`. The factor in (6) is monotone in
`|k_i|`, so

```text
Pi_i <= ((1-cos kappa)/(3+cos kappa))^2
        +epsilon_i(kappa).                               (8)
```

At low momentum,

```text
((1-cos kappa)/(3+cos kappa))^2
  =kappa^4/64+O(kappa^6).                                (9)
```

Thus a family whose field-energy spectrum narrows as `kappa=O(R^-1)` and whose
ultraviolet energy tail vanishes faster than `R^-4` has

```text
Pi_i=O(R^-4).                                            (10)
```

This is the precise local escape left open by FTD-0554. It suppresses rather
than exactly removes microscopic pinning.
