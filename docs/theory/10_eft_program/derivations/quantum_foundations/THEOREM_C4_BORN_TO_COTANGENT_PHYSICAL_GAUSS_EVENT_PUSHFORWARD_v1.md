## 1. Physical detector-cell resource

The prior prepared finite Born tape attached one C4 detector token to each
address-pair visit. Replace each fresh cell by the finite resource

\[
 \boxed{
 1\text{ detector C4 token}
 +8\text{ cotangent source records}.}              \tag{1}
\]

Thus every cell retains exactly nine finite tokens. The eight source records
are initially reserve capacity; their directed packet is computed reversibly
from the retained signal outcome, detector orientation, and a fixed local

## 2. One click is now a Gauss event

For a phase-compatible bright ordered pair, one gate simultaneously:

1. routes the detector cell to outcome $o$;
2. moves its C4 detector token from reserve to manifested bond ownership;
3. manifests opposite ternary endpoint states;
4. transfers the eight-record $D_4$ packet into active field ownership; and
5. orients that packet so its canonical electric edge has the boundary of the

With the conventional selection $\rho=-s$ for electric sign,

\[
 \Delta\operatorname{div}E=\Delta\rho             \tag{2}

the clicked cell returns all nine resources to their original reserves and
restores both endpoints to zero.

No signal or dark record is consumed. Source direction is not created from
nothing: it is a deterministic function of the still-retained outcome record,
orientation, and port registry.

## 3. Exact physical event count

Let $Z_o$ be the residual Gaussian-integer history sum at port $o$. The
coprime address orbit visits every ordered address pair exactly once. The
number of active manifested endpoint-plus-field events is

\[
 \boxed{M_o=|Z_o|^2}.                               \tag{3}

\[
 \frac{M_o}{\sum_r M_r}
 =\frac{|Z_o|^2}{\sum_r|Z_r|^2}.                   \tag{4}

local Gauss field source, not merely labels or copied signal records. A second
