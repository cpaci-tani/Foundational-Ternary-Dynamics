The same energy does not make every internal deformation translate:

- rotation mode `2` reaches only `0.55152232695...0.55152232697` cell and is

The engine therefore distinguishes two kinds of internal motion.  Strain
energy can remain almost entirely internal, while selected rotational
excitations couple strongly to the lattice translation coordinate.  This is
not explained by total energy alone and is consistent with the FTD-0614
finding that internal branch state controls access to translation routes.

## 4. What the result does not establish

The run records displacement magnitude but not the signed displacement vector
or an internal phase observable.  It therefore does not establish that the
two momentum signs reverse the walking direction, that the translation is
phase-controlled, or that a recurring internal cycle supplies persistent
motion.  The histories last only 128 ticks.

The largest field-plus-matter pseudomomentum defect is
`7.269458835935474e-4`, and the selected one-core state uses a uniform
neutralizer.  The result is therefore not isolated self-propulsion, a
conserved total-momentum theorem, an inertial particle, or an electromagnetic
matter claim.
