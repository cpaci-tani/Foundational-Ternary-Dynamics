# Theorem — Production genesis is not an amplitude lock or the written common action (FTD-0567)

**Status:** `[THEOREM — EXACT FROZEN-MAP ALGEBRA] + [CLOSED NEGATIVE — CURRENT GENESIS AS CONSERVATIVE AMPLITUDE LOCK]`
**Dependencies:** FTD-0425, FTD-0467, FTD-0564.
**Production effect:** none.

## 1. Statement

For an accepted single-substrate production genesis event, let

\[
r=|J|=k_g+x,\qquad x>0,
\]

and let `d` be `kinetic_drain`. The implemented update is

\[
J'=\left(1-\frac{k_g}{r}\right)J,
\qquad W'=(1-d)W.
\]

Therefore

\[
\boxed{|J'|=x},
\]

not `k_g`, and the accounted quadratic field withdrawal is

\[
\Delta H_J=k_gx+\frac{k_g^2}{2},
\qquad
\Delta H_W=\left(d-\frac{d^2}{2}\right)|W|^2.
\]

Consequently the current production transaction:

1. preserves the entire incoming overshoot `x` and does not project onto one post-genesis amplitude;
2. withdraws no fixed energy quantum that can be identified with one state-only ternary rest energy for all accepted inputs;
3. is not generated by the written local action, whose candidate-state dependence cannot see `|J|` at fixed divergence;
4. is non-invertible on the frozen variables once evaporation is admitted.

The current genesis/evaporation rules therefore cannot supply the conservative, algebraically invertible common-action amplitude lock required by FTD-0564.

## 2. Exact accepted-event map

Because `r>k_g`, the `max` in the production flux scaling is inactive:

\[
J'=\left(1-\frac{k_g}{r}\right)J.
\]

Taking magnitudes gives

\[
|J'|=r-k_g=x.
\]

Thus every `x>0` is a possible post-event magnitude. In particular, two accepted preimages with overshoots `x_1!=x_2` produce different post-event magnitudes. The map is a radial translation, not an amplitude projection.

The event probability

\[
p(x)=1-e^{-x/k_m}
\]

does not change that conclusion. Conditioning a point input at `x` on acceptance leaves its output at `x`. Choosing point inputs at two different positive overshoots proves that no input-independent accepted-event amplitude is produced. The stochastic law reweights an incoming distribution; it does not replace it by a universal one.

## 3. Energy withdrawal is not one state quantum

The field contribution is

\[
\begin{aligned}
\Delta H_J
&=\frac12\left[r^2-(r-k_g)^2\right]\\
&=k_gr-\frac{k_g^2}{2}\\
&=k_gx+\frac{k_g^2}{2}.
\end{aligned}
\]

The wave-velocity contribution is

\[
\Delta H_W
=\frac12\left[1-(1-d)^2\right]|W|^2
=\left(d-\frac{d^2}{2}\right)|W|^2.
\]

Even at fixed `W=0` and fixed `d`, the total withdrawal varies linearly with `x`. A single state-only energy assigned to `s=+1` or `s=-1` cannot balance all accepted events. A field-dependent interaction or reservoir could do so, but that would be an additional derived transaction; it is not the current state-only lock.

The dual-substrate path is sharper: it calls `manifest_at()` without changing `J` or `W`. Its quadratic field/wave payment is exactly zero while the ternary state changes. The two production genesis branches therefore do not implement one common latent-heat identity.

## 4. Uniform-field counterexample to the written action

At zero velocity, the implemented candidate-state-dependent local terms are

\[
L_s=B+g_csD-\lambda_G(D-s)^2,
\]

where `D=div J` and the Born term `B` is independent of `s` in the implementation.

Consider a spatially uniform periodic field `J=A e_x`, with `W=0`. For every `A`,

\[
D=0,\qquad \nabla J=0.
\]

Hence

\[
L_0=B,
\qquad
L_{+}=L_{-}=B-\lambda_G,
\]

independently of `A`. Take `A=k_g/2` and `A=2k_g`. The written action assigns identical candidate-state values to the two configurations, but production genesis is ineligible in the first and eligible in the second because its predicate is `|J|>k_g`.

No fixed rule that selects a candidate state from these implemented action values can reproduce the production magnitude threshold. Minimizing selects the manifested pair at both amplitudes; maximizing selects void at both amplitudes; either convention also leaves the two polarities degenerate at `D=0`. Production instead resolves the zero-divergence tie as negative because its code uses `D>0 ? +1 : -1`.

The action implementation contains no `K_GENESIS`, exponential acceptance factor, kinetic drain, evaporation erasure, or Higgs/manifestation potential. Its current regression is correctly scoped in code to field-sector stationarity and replay of selected production forces. The older documentation claim that `delta S=0` generates genesis and evaporation is therefore retracted.

## 5. Evaporation and inversion

Production evaporation applies

```text
s -> 0,
particle_id -> -1,
spin -> 0,
color -> 0,
```

without a compensating update to `J`, `W`, velocity, remainder, or latency. Distinct `s=+1` and `s=-1` preimages with otherwise identical continuous fields therefore reach the same post-event state. FTD-0425 already proves this with the live engine; FTD-0567 source-locks and composes that witness with the amplitude/action result.

A regular algebraically invertible discrete common-action transaction on the frozen state variables cannot equal this many-to-one map. This does not exclude a stochastic open-system law or a conservative lift with an explicit environment/history variable.

## 6. Relation to the earlier “amplitude ceiling” result

FTD-0316 measured a sharp **ignition threshold** in its registered coherent-wave arms: genesis did not fire below the configured `K_GENESIS` and did fire above it. That measurement survives.

Its stronger interpretation as an exact local amplitude ceiling does not. The exact accepted-event rule subtracts `K_GENESIS`; it does not set the residual magnitude to `K_GENESIS`. For `r>2K_GENESIS`, one accepted event still leaves a supercritical residual. The observed crest regulation in the registered dynamical runs is therefore a collective stochastic/dissipative behavior, not an algebraic hard cap.
