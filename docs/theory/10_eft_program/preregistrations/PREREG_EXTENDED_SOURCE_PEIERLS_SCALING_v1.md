## 2. Exact theorem locked before measurement

For any real periodic zero-mean base source `a(n)` with Fourier transform
`A(k)`, translate its FTD-0541 tensor quadratic coat by centered fraction `f`
along axis `i`. With

```text
b(k)=(3+cos k)/4,
lambda(k)=2 sum_j(1-cos k_j),
Q(f)=f^4-f^2/2,
```

the locked exact prediction is

```text
U_i(f)=U_0+C_i Q(f),

U_0=beta/(2 L^3) sum_(k != 0)
    |A(k)|^2 prod_j b(k_j)^2/lambda(k),

C_i=beta/(2 L^3) sum_(k != 0)
    |A(k)|^2 (1-cos k_i)^2
    prod_(j != i)b(k_j)^2/lambda(k).
```

The half-cell barrier is `Delta U_i=C_i/16`. Therefore its exact relative
value is

```text
Pi_i[a] = Delta U_i/U_0
        = < ((1-cos k_i)/(3+cos k_i))^2 >_(energy weight).       (1)
```

The weight is the nonnegative normalized summand defining `U_0`. Thus
`0 <= Pi_i <= 1`; it vanishes exactly only for an axis-invariant source, and
for energy supported within `|k_i| <= kappa` it obeys

```text
Pi_i <= ((1-cos kappa)/(3+cos kappa))^2
     = kappa^4/64+O(kappa^6).                                  (2)
```

If an energy fraction `epsilon` lies outside that band, the locked bound is
the right side of (2) plus `epsilon`. No fitted exponent enters this theorem.
