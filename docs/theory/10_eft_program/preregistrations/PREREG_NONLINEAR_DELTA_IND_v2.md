The v1 native closure `N=<N_calc,N_dyn>` is defined by `PREREG_DELTA_IND_CLOSURE_DEFINITION_v1.md`. ## 2. Frozen closure rungs

Both rungs retain v1's `N_calc`, uniform finite-description rule, algebraic initial/source data, algebraic assigned parameters, fixed arithmetic lattice ladder, fixed finite observables, and polynomial horizon/modulus policies. A coupling assigned a transcendental real remains an import and is outside both rungs.

### 2.1 `N_bounded`

`N_bounded` is v1's closure enlarged by native threshold/genesis, evaporation, collision/annihilation, movement/bounce, and other spec-level piecewise update events, subject to a finite integer event budget `B` named by the schema and independent of lattice size `L`. The total number of accepted nonlinear events along the schema history is at most `B`; the horizon is bounded by a fixed polynomial in `L`.

The **effective branch transcript** is frozen as the ordered list of accepted nonlinear events, each carrying: event type, lattice offset, tick, comparison result, and the algebraic pre/post-event local record needed to determine the subsequent linear segment. Rejected comparisons are not events, but any internal probability or comparison value used as an observable would have to satisfy the same algebraic-parameter and fixed-observable policy. An undecorated event-type string is not an effective transcript.

### 2.2 `N_unrestricted`

`N_unrestricted` uses the same uniform-description, algebraic-data/parameter, finite-observable, and polynomial horizon/modulus policies, but the number of nonlinear events may grow with `L` and the horizon.

No branch table, output table, L-indexed initial data, target constant, or externally supplied computation tape is admissible in either rung. A native computation generated by one uniform schema is admissible; its mere ability to print a chosen computable real would trigger IMPROPER rather than physical forcing.

## 3. Exact-arithmetic adequacy anchors

Both anchors are transition identities conditional on an explicit branch result. They test the spec-level algebraic update, not whether the production engine reaches the pre-state.

1. **Single-site threshold/genesis.** Start with `J=(5/2,0,0)`, `Jdot=(3/4,-1/2,1/4)`, rational threshold `k_g=3/2`, rational kinetic drain `1/3`, negative rational polarity signal `-2/5`, and accepted branch bit. The verifier must recompute strict supercriticality, post-drain `J=(1,0,0)`, post-drain `Jdot=(1/2,-1/3,1/6)`, and ternary state `-1`. The equality-at-threshold negative control must remain void and undrained.
2. **Two-particle collision/annihilation.** A `+1` source with x-remainder `3/4`, x-velocity `1/2`, and `dt=1` meets an adjacent `-1` target. The verifier must recompute the pre-collision remainder carry `1/4`, final states `(0,0)`, final remainders zero, and exact `1/6` face-neighbour flux bursts from the two frozen rational pre-collision flux vectors.

All arithmetic uses `fractions.Fraction`. Floating approximation, imported constants, engine execution, masses, and CODATA are forbidden.

## 4. Properness and characterization obligations

### 4.1 Bounded rung

The execution must distinguish:

- finiteness of the event alphabet and of undecorated words of length at most `B`; from
- finiteness, uniformly in `L`, of the effective space-time-decorated transcript class.

Only a proof of the second, plus a proof that every resulting finite interleaving of algebraic nonlinear maps and v1 linear segments remains in the v1 period/valuation upper bound (or an explicitly enumerated extension), passes properness/characterization. If event timing, location, or comparison data yields an unbounded class and no replacement characterization is proved, this rung is BLOCKED-ESCAPE. Countability alone is insufficient.

### 4.2 Unrestricted rung

The execution must deliver exactly one of: (a) a universal-computation/dense-computability embedding; (b) a structural non-universality obstruction and a proper characterized output class; or (c) an explicit proof that neither is currently established. Branching and collisions alone are not a universality proof; failure to find an embedding is not a non-universality proof.

### 4.3 Valuation order

The delta valuation may be run for a rung only after its properness and characterization gates pass. A programmable construction of delta before non-universality is established is IMPROPER, not REFUTED and not physical forcing. If properness succeeds, the v1 recomputing verifier must be rerun; a transcribed v1 verdict is invalid.

## 6. Frozen outcomes, precedence, and partition

Correctness gates are evaluated first; a failure is **INVALID** and no substantive verdict is booked. For each valid rung independently, apply this ordered decision list:

1. **IMPROPER:** a universality or dense-computability witness makes the closure non-informative for delta membership.
2. **REFUTED:** after properness/non-universality succeeds, delta is constructed inside the proper closure.
3. **PROVEN:** after properness and characterization succeed, the valuation excludes delta with no assumptions beyond v1's proven E0 basis.
4. **PROVEN-CONDITIONAL:** after properness and characterization succeed, the valuation excludes delta only under an explicit enumerated additional assumption package.
5. **BLOCKED-ESCAPE:** properness, non-universality, or output-class characterization remains undecided, or the bounded transcript class escapes the available valuation model without an improperness witness.

Partition proof: after validity, `universal`, `proper`, `delta_constructed`, `valuation_closes`, and `extra_assumptions` are Booleans/certified predicates. Row 1 takes `universal`; otherwise row 2 takes `proper and delta_constructed`; otherwise row 3 takes `proper and valuation_closes and not extra_assumptions`; otherwise row 4 takes `proper and valuation_closes and extra_assumptions`; every remaining dataset takes row 5. Ordered precedence prevents overlap. There are no numerical ties. Normative criteria and this decision list outrank rationale prose.
