## 1. Question

FTD-0896 proves that principal Bloch labels add only modulo reciprocal-lattice
vectors and that a real lift requires winding/history or nonlocality. What is
the minimum local update that retains the missing reciprocal carry during an
equal-and-opposite interaction, and does that update already supply physical
momentum or an energy-bearing substrate reservoir?

The registered answer is a conditional constructive theorem plus a boundary.
Given a supplied local dimensionless impulse increment, one integer reservoir
triplet is sufficient and uniquely updated to restore exact real additivity.
The update is reversible when the increment is reversibly available. It does
not derive the increment, the physical momentum unit, reservoir energy, or a
production substrate state.

## 3. Registered local carry theorem

Work first on one axis. For `k in [-pi,pi)`, define

```text
c(x) = floor((x+pi)/(2 pi)),
wrap(x) = x-2 pi c(x).
```

Let two principal labels receive a supplied local internal increment `+q` and
`-q`:

```text
k_1' = wrap(k_1+q),       c_1=c(k_1+q),
k_2' = wrap(k_2-q),       c_2=c(k_2-q).
```

Introduce one integer reciprocal reservoir `W` and update

```text
W' = W+c_1+c_2.                                  (1)
```

Then the real aggregate

```text
K_tot = k_1+k_2+2 pi W
```

is exactly conserved:

```text
k_1'+k_2'+2 pi W' = k_1+k_2+2 pi W.              (2)
```

The construction applies componentwise in three dimensions.

## 4. Uniqueness and reversal

Given the selected principal branch, reciprocal unit `2 pi`, and exact
conservation (2), the integer reservoir update is unique. If
`W'=W+d`, substitution forces `d=c_1+c_2`.

For reversal, apply `-q` to `k_1'` and `+q` to `k_2'`. Because each original
label is principal, the inverse carries are exactly `-c_1` and `-c_2`.
Equation (1) therefore returns `W` and both labels exactly.

This is a reversible local map only conditional on `q` being regenerated by
the inverse dynamics or retained in an event record. A supplied increment is
not an autonomous interaction law.

## 5. Particle-winding and substrate-reservoir partitions

An equivalent bookkeeping assigns individual windings

```text
w_1'=w_1+c_1,
w_2'=w_2+c_2.
```

Then each lifted label `k_i+2 pi w_i` follows the unwrapped increment and their
sum is conserved. Aggregating `W=w_1+w_2` recovers (1). The aggregate theorem
does not decide whether reciprocal carry belongs to a particle history, a
bond, a local substrate recoil cell, or a transported stress rail. That
partition is physical content still to be derived.

For a sequence of local interactions, reservoir increments telescope:

```text
W_N-W_0 = sum_events (c_1+c_2),
K_tot(N)=K_tot(0).
```

## 6. Physical scale and energy boundary

If `p_*` is an imposed conversion, the physical candidate is

```text
P_tot = p_* K_tot.
```

The carry algebra does not fix `p_*`. It also does not give the reservoir an
energy law. A periodic band energy satisfies

```text
epsilon(k+2 pi w)=epsilon(k),
```

so winding is invisible to the band energy. The same exact carry map is
compatible with `E_R(W)=0`, `E_R(W)=a W^2`, or other laws. Momentum closure
therefore does not pay for reciprocal recoil or produce self-dual energy.

If one additionally demands smooth phase-complete Hamiltonian exchange, a
bare integer count is insufficient: it needs a conjugate phase/action or an
explicit event-work/environment ledger. The existing selected phase-rail type
is a reference candidate for that additional structure, not a derivation of
native carry hardware.
