## 3. Frozen collective symplectic reduction

For `N>=1` selected constituent canonical pairs
`(x_a,p_a) in R^3 x R^3`, let `U in O(N)` have first row

```text
U_0a = 1/sqrt(N).
```

The remaining rows may be the Helmert basis. Apply `U` independently to each
spatial component:

```text
q_mu = sum_a U_mu,a x_a,
pi_mu = sum_a U_mu,a p_a.
```

Define the physical collective variables

```text
X = (1/N) sum_a x_a = q_0/sqrt(N),
P = sum_a p_a = sqrt(N) pi_0.
```

Orthogonality gives the exact one-form split

```text
sum_a p_a dot dx_a
  = P dot dX + sum_{mu=1}^{N-1} pi_mu dot dq_mu.
```

Consequently `(X,P)` is exactly three canonical pairs, is covariant under
signed spatial permutations, and is already present once the selected
constituent phase space exists. It is not generated by the scalar Gauss
reaction channel, and this result does not derive the constituents, their
graph, or their initial data.

## 4. Frozen conditional composite dispersion

Adopt the selected constituent energies

```text
E_a(p_a) = sqrt(epsilon_a^2 + c^2 |p_a|^2),
epsilon_a>0, c>0.
```

For a prescribed total momentum `P`, minimize `sum_a E_a(p_a)` subject to
`sum_a p_a=P`. Strict convexity and the Lagrange equations give a common
velocity and the unique allocation

```text
p_a = (epsilon_a/Epsilon) P,
Epsilon = sum_a epsilon_a.
```

The collective minimum is exactly

```text

d^2 E_coll/dP_i dP_j at P=0 = (c^2/Epsilon) delta_ij,
M_coll = Epsilon/c^2.
```

For identical constituents, `M_coll=N epsilon/c^2`. This is a conditional
composition theorem, not a derivation of `epsilon_a`, `c`, or the absolute
mass scale.

If a static binding/field offset `U_0` is merely added to the energy while not
participating in the boosted family, then

```text

M_inertial = Epsilon/c^2,
```

so `E_rest/c^2=M_inertial` fails whenever `U_0 != 0`. Rest-energy equivalence
therefore requires the dressing to participate in the common boost; it cannot
be inferred by adding a static binding constant.
