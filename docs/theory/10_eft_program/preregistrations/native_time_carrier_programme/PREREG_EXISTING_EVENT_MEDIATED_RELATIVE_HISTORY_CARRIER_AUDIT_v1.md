## 3. Registered relative-zero invariant

At each site define

\[
D=J_L-J_R,\qquad P_D=P_L-P_R.                                      \tag{1}
\]

Audit every frozen ordinary production mutation of the dual fields. The
registered classification is:

- equal L/R wave kicks, common coupling, ordinary injection, and Gauss
  correction act identically on the halves;
- damping and boundary sponge multiply both halves by the same scalar;
- weak transmutation swaps L/R;
- dual genesis and pair production do not write the L/R fields;
- void movement transfers the same scalar fraction of L and R;
- annihilation clears and distributes L and R by the same rule; and
- absorbing boundaries clear both halves.

Every listed action is homogeneous in `(D,P_D)` or leaves it unchanged.
Therefore the submanifold

\[
D=P_D=0\quad\hbox{at every site}                                   \tag{2}
\]

must be invariant under their composition. Selected asymmetric particle,
wavepacket, neutrino, or molecule constructors are external preparations and
are not an autonomous occupancy-event deposit. Their existence must be
reported, not hidden.

If (2) survives the source audit, the present production event stack cannot
create a relative history record from its ordinary symmetric vacuum.

## 4. Weak-exchange survivor

For a fired weak event, the frozen local action is

\[
(s,D,P_D)\mapsto(-s,-D,-P_D).                                      \tag{3}
\]

The certificate must prove that (3) is an exact involution and symplectic on
the relative pair. This is genuine reversible local chirality exchange.

It is not a transported direction/history carrier: it leaves spatial support
fixed, writes no displacement label, and maps zero relative data to zero.
Moreover, the production decision to fire depends on a threshold and a
tick/site-keyed random draw; the observation journal records the branch but
is not ontic substrate state.

## 5. Void-movement transfer gate

When a manifested voxel moves into a void target, production computes

\[
f={\min(\rho,K_B)\over\rho},\qquad 0<f\le1,                         \tag{4}
\]

and transfers the same fraction of L and R flux. For one scalar relative
component at source `i` and target `t`,

\[
\begin{pmatrix}D_i'\\D_t'\end{pmatrix}
=A_f\begin{pmatrix}D_i\\D_t\end{pmatrix},\qquad
A_f=\begin{pmatrix}1-f&0\\f&1\end{pmatrix}.                       \tag{5}
\]

Production does **not** transfer `wave_vel_L/R`, hence

\[
(P_{D,i}',P_{D,t}')=(P_{D,i},P_{D,t}).                              \tag{6}
\]

The registered consequences are:

1. zero relative data remains zero, so movement advects only a preloaded
   relative field;
2. for `f=1`, `det A_f=0`, and source/target relative factorization is
   noninjective;
3. for `0<f<1`, the phase-space map `diag(A_f,I)` is not symplectic because
   canonical momenta are not transformed by `A_f^{-T}`; and
4. the moved mechanical `velocity` and current occupancy crossing may retain
   a present hop direction, but equation (5) does not write that direction
   into `D`, export cumulative history, or define a relative source debit.

The `f=1` witness is mandatory because it is an exact production branch when
`0<rho<=K_B`, not a limiting argument.

## 6. Remaining event gates

The certificate must classify exactly:

- **dual genesis:** changes actual state/metadata from a chirality threshold
  and random draw but leaves L/R flux and wave velocity untouched; no relative
  deposit and no registered inverse;
- **evaporation:** clears actual labels while retaining fields; distinct
  manifested labels can reach the same post-state, so the full action is
  noninjective;
- **pair production:** chooses one of six axial directions from the dominant
  observable-flux component and writes observable fields/states, but not
  L/R fields; the source itself states that no common-action energy identity
  is implied;
- **same-sign bounce:** reflects selected mechanical velocity components but
  resets the remainder, so distinct admissible pre-remainders can have one
  post-state; it does not write relative data;
- **annihilation:** clears states, IDs, labels, and L/R source flux, then
  distributes L/R flux over face shells by the same linear rule; it is
  homogeneous on `D`, leaves `P_D` undistributed, and is noninjective on the
  complete state because cleared labels are not reconstructible;
- **absorbing boundary:** clears state and L/R flux and is noninjective;
- **reflective boundary:** flips mechanical velocity but resets the remainder;
  and
- **damping/sponge:** scales both relative coordinates equally, supplies no
  direction label, and has no booked bath/source transaction in this carrier
  audit.

An event may conserve an aggregate or implement a useful collision response
without satisfying the history-carrier contract.

## 7. Composition and journal gate

Composition cannot create relative data from zero if every component action
preserves (2). Nor can a composition become injective after an earlier branch
has identified two complete pre-states: if `A(x)=A(y)` for `x!=y`, then
`B(A(x))=B(A(y))` for every later deterministic map `B`.

The history journal stores before/after `Voxel` snapshots and can externally
reconstruct which branch fired. Its own frozen header says it is read-only,
disabled by default, consumes no randomness, and never writes production
state. It must not be used to repair production injectivity.
