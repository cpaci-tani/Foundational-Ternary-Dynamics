## 1. Question

FTD-0569 proves that a finite-information local sidecar cannot reverse the
indefinitely repeated production genesis/evaporation cycle. It also notes that
one exact real can hide an infinite symbolic past. This registration resolves
the remaining ambiguity:

1. construct the exact-real natural extension rather than merely citing it;
2. determine whether the frozen `(J,W)` genesis drain is itself canonical;
3. construct the strongest branchwise energy-conserving symplectic lift if
   additional conjugate/environment variables are admitted;
4. expose the finite-precision and nonequilibrium costs explicitly.

This is observer-only. It does not add a bath, change the RNG, alter genesis or
evaporation, introduce a toggle, or claim that exact real numbers are physical
storage devices.

## 3. Locked theorem candidates

### N1 — Two-sided generalized-baker natural extension

Introduce an environmental canonical pair `(u,v) in [0,1)^2`. For fixed
`0<p<1`, define

```text
b=1 (accepted): U=u/p,             V=p*v,             u<p,
b=0 (rejected): U=(u-p)/(1-p),     V=p+(1-p)*v,       u>=p.
```

The inverse branch is read from `V`:

```text
V<p:   u=p*U,             v=V/p,
V>=p:  u=p+(1-p)*U,       v=(V-p)/(1-p).
```

Each branch has Jacobian determinant one, the two images partition the unit
square, and Lebesgue measure is preserved. Repeated outcomes are retained in
successively finer digits of `v`; no external branch word is required in exact
real arithmetic.

Test the three production probabilities generated by
`x={0.125,0.5,1.25}`, together with `p={1/4,1/2,3/4}`. Use two interior `u`
values per branch and `v={0.2,0.8}`. Require branch, interval, inverse, and
Jacobian residuals below `1e-12`. Independently prove arbitrary-depth rational
inversion with exact fractions for `p={1/4,1/2,3/4}`.

This result must be classified as a **finite-dimensional but
infinite-information** dilation. It does not contradict the FTD-0499 or
FTD-0569 finite-capacity theorem.

### N2 — Frozen `(J,W)` genesis is not a canonical map

Temporarily interpret `J` as a canonical coordinate and `W` as its conjugate
momentum. The accepted flux Jacobian is

```text
A = (1-kg/r) I + (kg/r) n n^T,   n=J/r,
```

with radial eigenvalue `1` and two tangential eigenvalues
`t=x/(x+kg)`. The momentum block is `a I`. A block map
`(J,W)->(J',W')` of this form is symplectic only if `A^T aI=I`. Its radial and
tangential defects are

```text
delta_rad = a-1 = -d,
delta_tan = a*t-1 < 0.
```

For every registered accepted arm, require the analytic defect formula to
match the matrix residual below `1e-12`, `1-a*t>0`, and the raw six-dimensional
Jacobian

```text
det DF_raw = t^2 a^3
```

to lie strictly below one. Therefore no action claim on the frozen canonical
pair is licensed even if N1 succeeds.

### N3 — Branchwise symplectic energy lift with added primitives

Treat all six components `q=(J,W)` as configuration coordinates and add their
six conjugates `pi`. Add the phase pair `(u,v)` and a time--reservoir-energy
pair `(tau,R)`. This is a sufficient construction, not a minimality claim.

For branch `b`, use the type-2 phase generators

```text
S_1(u,V;p) = u V/p,
S_0(u,V;p) = (u-p)(V-p)/(1-p).
```

They reproduce N1 through `v=dS_b/du`, `U=dS_b/dV`. Let
`g_b=dS_b/dp`, so on the realized branches

```text
g_1 = -u*v/p,
g_0 = U*v-U-v.
```

The full branch generator is

```text
F2_b(q,u,tau;Pi,V,R')
  = F_b(q).Pi + S_b(u,V;p(q)) + tau*(R'-D_b(q)).
```

It gives

```text
Q   = F_b(q),
R'  = R + D_b(q),
tau'= tau,
Pi  = DF_b(q)^(-T) [pi - g_b grad p + tau grad D_b].
```

Consequently the enlarged map is branchwise symplectic by construction and
conserves

```text
K = (|q|^2)/2 + R.
```

Run exactly 4,320 arms:

- ten flux directions;
- three excesses `{0.125,0.5,1.25}`;
- three wave vectors;
- drains `{0,0.5,0.9}`;
- accepted and rejected branches;
- `v={0.2,0.8}`;
- two six-component conjugate vectors;
- `tau={-0.4,0.7}`.

Require maximum forward/inverse state residual below `1e-11`, energy residual
below `1e-12`, and every generating-equation residual below `1e-12`.

Passing N3 means only that an enlarged selected mathematical action exists.
It does not derive the ten added continuous variables, their physical
interpretation, their initialization, or their transport between sites.

### N4 — Binary64 cannot carry the exact natural extension indefinitely

At `p=1/2`, start from `v=0`. Compare two 64-branch histories that differ only
in their first branch and then take the upper/rejected branch 63 times. Their
exact values differ, but both must round to the same binary64 value. Record the
collision and loss of the `[0,1)` invariant if it occurs.

The exact-fraction proof must retain the distinction. No tolerance-based
near-match is credited: the binary64 values must be bit-identical.

### N5 — Projected production remains absolutely irreversible

For an accepted genesis pair `a->b`, the frozen kernel has `P(a,b)>0` and
`P(b,a)=0`. The pathwise log forward/reverse probability ratio is therefore
`+infinity`. The natural extension avoids this only because the reverse state
includes the environmental coordinates and conjugates omitted by production.

This forbids equilibrium/detailed-balance language for the projected kernel.
It does not forbid a driven reversible microscopic environment.
