## 1. Question

FTD-0578 closes the compact point carrier because its reciprocal Moore/Hodge
action has a diagonal time-centering mismatch and a nonzero Peierls
self-force. This campaign asks whether replacing the point by any nonzero
finite rigid base source can remove either defect exactly, and how quickly a
smooth locally generated envelope can suppress them.

No self-field subtraction, fitted counterforce, deforming internal schedule,
volume-spanning source, production toggle, scenario, or tolerance change is
permitted.

## 2. Frozen finite rigid carrier

Let a nonzero real finite-support base source be

```text
a(n),                  A(z)=sum_n a(n) z^(-n).           (1)
```

All coefficients undergo the same straight CIC displacement `d`, with active
components `d_i in {-1,0,+1}`. Define

```text
u_i=z_i^(-d_i)-1,
P_d(t)=product_(i:d_i!=0) (1+t u_i),
T_d=integral_0^1 P_d(t) dt,
H_d=(1+z^(-d))/2,
M_d=T_d-H_d.                                             (2)
```

After the FTD-0577 coat, the aggregate time-centering mismatch is

```text
Delta_d(z)=B_M(z) A(z) M_d(z).                           (3)
```

The exact path-class factors must be

```text
axial: M_d=0,

edge:  M_d=-(u_i u_j)/6,

body:  M_d=-(u_i u_j+u_i u_k+u_j u_k)/6
             -(u_i u_j u_k)/4.                          (4)
```

The Laurent-polynomial ring over the reals is an integral domain. Since
`B_M`, every nonzero finite `A`, and each diagonal `M_d` are nonzero,
`Delta_d` cannot vanish identically for an edge or body path. Periodic tests
must use boxes larger than the unwrapped product support so quotient-ring
zero divisors cannot fake cancellation.

## 3. Arbitrary-carrier Peierls law

For a common fractional axial displacement `r`, the source symbol is

```text
rho_hat_r=B_M A [(1-r)+r exp(-i k_i)].                   (5)
```

Using the exact FTD-0575 response

```text
R_H(k)=3 sum_j sin(k_j)^2/M(k),                          (6)
```

the same eliminated common action must give

```text
V_self(r)=V_self(0)+C_i[a] r(1-r),                      (7)

C_i[a]=(G_C^2/L^3) sum_k R_H(k)|B_M(k)A(k)|^2
                              (1-cos k_i).              (8)
```

On the infinite lattice, `C_i[a]>0` for every axis and every nonzero
finite-support `a`: the summand is nonnegative; `R_H`, `B_M`, and
`1-cos(k_i)` are strictly positive on an open set; and a nonzero Laurent
polynomial cannot vanish on an open set. Fixed finite profiles must retain
strict positivity on both registered nonwrapping volumes.

With

```text
U_0=(G_C^2/(2L^3)) sum_k R_H |B_M A|^2,
w(k)=R_H |B_M A|^2 / sum_q R_H |B_M A|^2,               (9)
```

the exact relative barrier is

```text
Pi_i[a]=(C_i/4)/U_0
       =(1/2) sum_k w(k)(1-cos k_i),   0<Pi_i<=1.       (10)
```

This is the Moore/Hodge spectral pinning index. It has one power of
`1-cos(k_i)`, unlike the two-power quadratic-coat index in FTD-0555.

## 4. Smooth-envelope asymptotics

Use the selected continuous control family

```text
h_m(n)=2^-m binomial(m,n),
a_m(n_x,n_y,n_z)=product_j h_m(n_j).                    (11)
```

It is generated by repeated local averaging but is not a primitive ternary
carrier. Including the Moore coat gives

```text
|B_M A_m|^2=product_j cos(k_j/2)^(2N),  N=m+2.          (12)
```

Since `R_H(k)=3+O(k^2)`, Gaussian rescaling must yield

```text
U_0 ~ [3 G_C^2/(2 pi^(3/2))] N^(-3/2),
C_i ~ [3 G_C^2/pi^(3/2)] N^(-5/2),
Delta V_i ~ [3 G_C^2/(4 pi^(3/2))] N^(-5/2),
Pi_i ~ 1/(2N).                                          (13)
```

The exact binomial time-centering ratios are

```text
||Delta_edge||_2^2 / ||B_M a_m||_2^2
  =1/[9(N+1)^2],

||Delta_body||_2^2 / ||B_M a_m||_2^2
  =[2(N+1)-1]/[6(N+1)^3].                              (14)
```

Thus both relative pinning and relative L2 centering mismatch fall only as
`O(N^-1)=O(R_rms^-2)`, not exactly to zero at finite construction depth. The
Peierls suppression is parametrically slower than the `O(R^-4)`
quadratic-coat result of FTD-0555 because the present CIC/Hodge transaction
has only a first-power alias penalty.
