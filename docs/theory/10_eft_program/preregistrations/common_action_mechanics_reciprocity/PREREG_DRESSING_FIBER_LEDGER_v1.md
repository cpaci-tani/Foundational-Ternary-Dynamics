# PRE-REGISTRATION — Dressing-fiber ledger v1

## Question

Given the FTD-0494 proof that cusp work is not a single-valued state function
of the frozen local variables, what is the minimum additional state needed to
record that work reversibly, and can that extension preserve both centered
motion and an ordinary common action?

## Candidate extension

Introduce one real observer coordinate `D` carried with the manifested
history and update it by

```text
D_1-D_0=W_cusp=W_field-W_center.
```

For a centered matter transaction,

```text
Delta E_field=-W_field,
Delta E_matter=+W_center,
Delta D=+W_cusp,
```

so the extended scalar ledger closes exactly.  The reverse event must subtract
the same cusp work and recover `D_0`.

The path connection is non-exact.  For the FTD-0494 Gauss-free plaquette,
parallel transport along `xy` and `yx` must end with fiber values differing by
the measured holonomy `0.438`; the oriented closed loop `xy-yx` must shift
`D` by that amount and the exactly reversed loop must undo it.

## Ordinary-action discriminator

The standard discrete constraint term is

```text
S_constraint=lambda[W_cusp-(D_1-D_0)].
```

Variation with respect to an interior `D_k` forces the adjacent multipliers to
be equal, so `lambda` is a conserved conjugate quantity.  Selecting
`lambda=1` makes the position variation contribute `grad W_cusp`, which must
restore the one-sided branch derivative identified by FTD-0494.  Therefore:

- a bookkeeping-only `D` may retain centered motion but is not generated by
  the same ordinary action;
- an ordinary variational `D,lambda` pair restores the cusp force and inherits
  FTD-0491 branch nonuniqueness.

## Locked tests

1. Require extended energy closure and single-step reversal below `1e-12` for
   both polarities, translations, and cubic transforms.
2. Require `D_xy-D_yx` and the oriented closed-loop shift to reproduce the
   FTD-0494 holonomy below `1e-12`, with a nonzero magnitude above `1e-6`.
3. Require exact reversal of the full closed loop below `1e-12`.
4. Require the discrete multiplier equation
   `partial S/partial D_k=lambda_k-lambda_(k-1)` exactly and constant
   multipliers on shell.
5. At `lambda=1`, require the constraint position gradient to equal the cusp
   gradient and reconstruct the ordinary branch derivative below `1e-12`.
6. Show that changing `D_0` by an arbitrary constant changes no work,
   trajectory, or holonomy diagnostic.  The extension therefore adds a new
   undetermined energy zero as well as a history coordinate.

## Frozen verdicts

- `SCALAR_FIBER_CLOSES_COMMON_ACTION` only if one scalar closes energy,
  remains path-independent, and its ordinary variation does not restore the
  branch derivative.
- `SCALAR_LEDGER_CLOSES_BOOKKEEPING_NOT_COMMON_ACTION` if energy and reversal
  close but the fiber has nonzero holonomy and ordinary variation restores the
  cusp/branch force.
- `IMPLEMENTATION_INVALID` if energy, reversal, holonomy, symmetry, or
  multiplier identities fail.

## Consequence

This is an observer-only minimal-extension audit.  It does not authorize a
new production variable.  A positive bookkeeping construction accompanied by
the action obstruction prices the next ontology explicitly: at least one real
history coordinate for bookkeeping, and an additional conjugate quantity for
a standard variational completion.
