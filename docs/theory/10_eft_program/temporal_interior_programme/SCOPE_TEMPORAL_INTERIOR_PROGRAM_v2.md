## 0. Binding ceiling

This programme may establish conditional mathematical theorems inside an
adopted potentiality type and may construct deterministic reference models.
It may not call those constructions substrate derivations. In particular:

- the algebraic state–effect rule is not the physical Born pushforward;
- a singlet reference model is not a native Bell mechanism;
- `G*` in a selected quartic period is not a native clock carrier; and
- operational no-signalling is not proof that the preferred global tick is
  empirically hidden.

## 2. Stop conditions

The branch is archived closed negative if any load-bearing interface is
mathematically inconsistent. A physical candidate is closed negative in its
registered scope if it requires target-coded Born weights, operational
signalling, context-dependent clock control, or an observable preferred-order
effect above the locked tolerance.

Failure of a physical candidate does not refute the consistency of the
adopted v2 formalism; failure of the formal net or selector contract blocks
ratification of the constitution itself.
