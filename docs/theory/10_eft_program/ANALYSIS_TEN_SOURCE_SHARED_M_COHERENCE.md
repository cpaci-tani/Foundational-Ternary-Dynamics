## What the refinement removed

FTD-0590 assigned one independent coefficient in `[-1,1]` to every cubic
momentum orbit. The native pulse law only permits one coefficient per exact
stencil eigenvalue. FTD-0594 grouped the orbits using the exact integer class
of `6M` in `Z[x]/(Phi_L)` and summed their characters before taking absolute
values.

This removes all relaxation caused solely by equal `M` values.

## What survived

The refinement is almost vacuous on the registered large quotients:

- `L=17`: all 164 cubic orbits have distinct `M`;
- `L=65`: all 6,544 cubic orbits have distinct `M`;
- `L=33`: one 22-orbit shell exists, but it does not change the global norm;
- `L=9`: one six-orbit shell lowers `mu` by only `0.0017706026`.

The decisive `L=65,r=9` upper bound is unchanged. This establishes that the
FTD-0593 failure is not mainly caused by overlooking exact eigenvalue
degeneracies.

## Remaining relaxation

Two independent enlargements remain:

1. every source pair is allowed to attain the worst displacement coherence
   simultaneously, although nine distinct sites cannot realize arbitrary pair
   distances independently;
2. the bounded pulse factors on distinct `M` shells are treated as independent,
   although each source's full vector is generated by integer times through
   one trigonometric law.

The first is a finite combinatorial geometry problem. The second is a
simultaneous Diophantine/phase-feasibility problem. Neither is resolved by
FTD-0594.
