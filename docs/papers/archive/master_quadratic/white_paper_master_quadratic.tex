Time emerges as ordering between events. Waves, motion, and probability distributions exist \textit{between} moments, not within them. Wave function ``collapse'' is Bayesian updating by systems with $\geq 2$ logic gates. The quadratic is a structural property requiring no observer.
\end{abstract}

\section{The xyztg$\psi$ Ontology}

We seek the minimal ontic structure for physical reality without privileging observers or conflating events with laws.

\subsection{The Three Primitives}

\textbf{Event (xyzt)}: The fundamental ontic unit. An irreducible fact: something happened here-now. A single event contains no motion, pattern, or wave. If $t = 0$, no event has occurred. A single event is complete.

\textbf{Geometric Constraint ($g$)}: Encodes metric and causal structure. Constrains distances, durations, causal adjacency. Gravity is not a force but a constraint on spacetime relations. Inferred from relations among events, not directly observed.

\textbf{Modal Constraint ($\psi$)}: Not an event or aggregate. A law-like constraint governing which events can occur with what relative likelihood. Does not ``happen'' at a moment; constrains transitions between moments.

\subsection{The Single Moment}

A single moment is fully described by:
\begin{equation}
\textbf{xyztg}\psi
\end{equation}

\begin{itemize}
\item $xyzt$: that an event occurred here-now
\item $g$: geometric context making ``here'' and ``now'' meaningful
\item $\psi$: modal constraint that made this event possible
\end{itemize}

Everything else exists \textit{between} moments, not within them.

\subsection{Time as Ordering}

Time is not a primitive object or container. Time emerges as the ordering relation between events:
\begin{equation}
E_1 \prec E_2
\end{equation}

From ordering alone arise: before/after, duration, change, history. No observer is required for ordering to exist.

\textbf{You can have $(x,y)$ without $t$. You cannot have $t$ without $(x,y)$.}

Space can exist as static fact. Time requires substrate. Spatial existence is primitive; time is emergent.

\subsection{Waves Exist Between Moments}

A wave is not an instantaneous thing. It is a structured constraint on possible events across time. Wave-like behavior emerges only across multiple events.

At any single $(x,y,z,t)$, a particle either exists or does not. ``Superposition'' describes the $\psi$-constraint over multiple potential events, not a property of a single moment.

\subsection{Minimal Causal Structure}

Two events are connectable iff:
\begin{equation}
\text{Connectable}(E_1, E_2) \iff g(E_1, E_2) \land \psi(E_1 \to E_2) > 0
\end{equation}

Geometric admissibility ($g$): spacetime relation is allowed.

Modal admissibility ($\psi$): transition has nonzero amplitude.

Causality means: an event restricts events that may follow. No meaning or observer required.
