\addcontentsline{toc}{chapter}{How to Read This Document}
\markboth{How to Read This Document}{How to Read This Document}

\noindent
This document maps the complete six-layer ontological chain of Foundational
Ternary Dynamics (FTD)---
\[
  \textsc{Ontology} \;>\; \textsc{Logic} \;>\; \textsc{Mathematics}
  \;>\; \textsc{Philosophy} \;>\; \textsc{Physics} \;>\; \textsc{Science}
\]
---in the order the constitution declares it (\ftdid{0254}). It is a
\etag{syn} document: it re-states existing canonical claims at their canonical
tags and \emph{introduces no new mathematics}. Its purpose is to be read
\emph{map-first}: an external reader should be able to take in the whole chain
from the Master Chain DAG (Figure~\ref{fig:masterdag}) and then walk each layer
to see the one move it makes and exactly how far that move is established.

\paragraph{The reading discipline.} Each layer is \emph{constructed from} the
layer before it and \emph{accountable to} the layer after it: mathematics is
built on the ontology and logic that precede it; physics must answer to the
science (measurement) that follows it. Every load-bearing claim below carries an
epistemic tag and, where one exists, its provenance identifier (\ftdid{NNNN}),
so the claim can be traced back into the project's ledgers. The tags are where
the honesty lives; read them first.

\begin{conditionalbox}[The precedence rule]
Where this document disagrees with the \textsc{ledger}
(\texttt{LEDGER.md}), the constitution (\texttt{SPEC\_FTD\_FRAMEWORK\_V1.md}), or
the algebraic spine (\texttt{SPEC\_ALGEBRAIC\_SPINE.md}) on any tag or value,
\textbf{those documents are correct and this one has a bug}---please file it.
The ordering is \textsc{ledger} $>$ constitution $>$ this document.
\end{conditionalbox}

\paragraph{How epistemic status is shown.} Status is carried \emph{without
colour}, by rule style alone, so it survives grayscale and monochrome print. A
heavy rule is \textsc{forced}; a thin rule is \textsc{conditional}; a dashed
rule is \textsc{conjectural}; a double rule is a \textsc{boundary}---a mapped
wall or an open kernel. The same vocabulary governs the DAG: a double-ringed
node is an axiom or a framework declaration, a solid box is theorem-grade, a
dashed box is below theorem grade, and a double-ruled box is a boundary.
