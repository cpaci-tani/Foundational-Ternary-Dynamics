\begin{center}\footnotesize
This monograph was set in Times-like \textsc{newtx} with \LaTeX\ on the
\texttt{ftdmonograph} class. Its design is deliberately monochrome: epistemic
tier is carried by rule weight and style (heavy, thin, dashed,
double), never by colour, so the argument reads identically in grayscale and
in print, after Bringhurst's counsel that structure should be legible without
ornament~\cite{bringhurst2004}. Every constant and equation is defined once, in
a single macro file; every result is set at the grade it earned, and none was
inflated in the typesetting.
\end{center}
