Where do the workspace tabs go in side-mount?

The current tab bar is a horizontal strip (Controls · Charts · Lagrangian · Inspector · Zoo · Physics · ...). In a narrow sidebar, it needs to re-home. In bottom-mount it stays as today.

A

Vertical icon rail on the outer edge

Icon-only tabs stacked vertically on the edge nearest the viewport (right edge when left-mounted, left edge when right-mounted). Tooltips reveal labels. Saves horizontal space; all tabs always visible; reads like VS Code's activity bar.
