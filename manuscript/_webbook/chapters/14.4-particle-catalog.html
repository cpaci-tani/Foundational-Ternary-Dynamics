84  Particle Catalog

“The complete bestiary: mass relations and numerical fits within the framework”

ImportantMajor Update: Masses Are Derived

This catalog compiles the mass relations used in the Lemniscate-Alpha program and companion material, using four integers: b₃=7, N_c=3, N_eff=13, N_base=4. Masses are shown as ratios to electron mass m_e = 0.511 MeV/c².

84.1 Fundamental Fermions

84.1.1 Quarks (State: +1)

Quarks are the fundamental constituents of hadrons. The catalog presents the framework’s proposed mass relations in a uniform format.

WarningEpistemic Status: Numerical Fits

Unlike lepton masses (which follow pure integer arithmetic: muon = 3×70 - 3, tau = 17×207 - 42) and the proton mass (which has two independent derivation paths converging via G*), the quark mass formulas below are numerical fits: combinations of framework integers that match experimental data to <1% accuracy but lack an underlying connecting principle.

An underlying principle connecting these formulas remains an open research question.

84.3 Composite Particles: Baryons

WarningEpistemic Status: Composite Particles

Nucleons (proton, neutron) have framework derivations with sub-percent accuracy.

All other composite particles (strange baryons, mesons, heavy hadrons) use [DATA] from PDG 2024. Framework derivations for these masses remain an open research question. Values are included for reference completeness.

84.3.1 Baryon Mass Derivations

Baryon Formula m/m_e MeV/c² Error
Proton 6π⁵ ≈ N_eff/α + T(10) 1836.15 938.3 0.002% / 0.017%
Neutron m_p + (φ² - 12α) 1839.0 939.6 0.04%

Where T(10) = 55 is the 10th triangular number, and (n-p)/m_e = φ² - 12α = 2.53.

NoteTwo Paths to the Proton Mass

The proton mass has two independent formulas: the pure geometry path (6π⁵ = 1836.118, 0.002% error) and the framework integer path (N_eff/α + T(10) = 1836.47, 0.017% error). Both converge via G*⁷ × (12/13). See Chapter 81 for the full derivation.

84.7.2 Composite Particle Factory

def create_proton(center_position):
    """Create a proton triad at given position."""
    # Equilateral triangle in xy-plane
    offset = 0.707  # sqrt(2)/2 for unit separation
    positions = [
        center_position + [0, offset, 0],      # up
        center_position + [-offset, -offset/2, 0],  # up
        center_position + [offset, -offset/2, 0],   # down
    ]

    quarks = [
        create_particle('up', positions[0]),
        create_particle('up', positions[1]),
        create_particle('down', positions[2]),
    ]

    # Lock the triad
    for q in quarks:
        q.is_locked = True

    return Proton(quarks)

def create_hydrogen(center_position):
    """Create hydrogen atom: proton + electron."""
    proton = create_proton(center_position)

    # Electron at shell radius
    electron_pos = center_position + [5, 0, 0]  # n=1 shell
    electron = create_particle('electron', electron_pos)
    electron.shell_n = 1

    return HydrogenAtom(proton, electron)
