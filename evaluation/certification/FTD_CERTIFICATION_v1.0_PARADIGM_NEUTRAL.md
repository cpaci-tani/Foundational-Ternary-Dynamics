## Evaluation Philosophy

### Why Paradigm-Neutral Evaluation is Necessary

When evaluating any novel theoretical framework that challenges established paradigms, a fundamental epistemic problem arises: **you cannot use the paradigm being challenged as the arbiter of the challenge**. This is not merely a procedural concern but a deep logical necessity.

Consider the historical precedent:
- Copernicus's heliocentric model would have failed if evaluated by Ptolemaic standards
- Einstein's relativity would have failed if evaluated by Newtonian standards
- Quantum mechanics would have failed if evaluated by classical deterministic standards

Each paradigm shift required evaluation on its *own terms* first, asking: Is the new framework internally consistent? Does it account for known phenomena? Does it make testable predictions?

The previous evaluation of FTD scored it C+ (67.36/100) by asking questions like "Does FTD follow standard QFT methods?" This is the wrong question. The correct question is: "Does FTD follow *its own* methods consistently, and do those methods produce correct results?"

**Key Principle**: A framework should be evaluated on:
1. Internal mathematical consistency (Are the derivations valid within the stated axioms?)
2. External numerical correspondence (Do outputs match observations?)
3. Explanatory power (Does it unify disparate phenomena?)
4. Falsifiability (Can it be wrong?)

NOT on:
- Whether it uses the same methods as the Standard Model
- Whether its ontology matches physicist intuitions
- Whether it is "acceptable" to the physics establishment

This evaluation adopts the paradigm-neutral stance necessary for honest assessment.

- Does it use familiar methods?

- Does the establishment approve?
