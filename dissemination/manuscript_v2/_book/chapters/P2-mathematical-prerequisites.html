2  Mathematical Prerequisites

This chapter collects the mathematical tools used throughout the manuscript. The reader is assumed to know quantum field theory, general relativity, and lattice gauge theory. This chapter provides only FTD-specific notation and identities.

2.1 P.2.1 Discrete differential geometry on \(\mathbb{Z}^3\)

The lattice operators on a scalar field \(\phi : \mathbb{Z}^3 \to \mathbb{R}\) and vector field \(\mathbf{A} : \mathbb{Z}^3 \to \mathbb{R}^3\):

Gradient (forward difference): \[ (\nabla \phi)_\mu(v) = \phi(v + \hat{e}_\mu) - \phi(v) \tag{P.1} \]

Divergence: \[ (\nabla \cdot \mathbf{A})(v) = \sum_{\mu=1}^3 \left[ A_\mu(v) - A_\mu(v - \hat{e}_\mu) \right] \tag{P.2} \]

Curl: \[ (\nabla \times \mathbf{A})_\mu(v) = \epsilon_{\mu\nu\rho} \left[ A_\rho(v + \hat{e}_\nu) - A_\rho(v) - A_\nu(v + \hat{e}_\rho) + A_\nu(v) \right] \tag{P.3} \]

Laplacian (6-neighbor SC stencil): \[ (\nabla^2 \phi)(v) = \sum_{\mu=1}^3 \left[ \phi(v + \hat{e}_\mu) + \phi(v - \hat{e}_\mu) - 2\phi(v) \right] \tag{P.4} \]

Laplacian (26-neighbor Moore stencil): \[ (\nabla^2_M \phi)(v) = \sum_{\delta \in N^M(v) \setminus \{v\}} w_\delta \left[ \phi(v + \delta) - \phi(v) \right] \tag{P.5} \]

with weights \(w_\delta = 1/|\delta|^2\) (inverse distance squared): \(w_{\text{SC}} = 1\), \(w_{\text{FCC}} = 1/2\), \(w_{\text{BCC}} = 1/3\).

2.2 P.2.2 Momentum space

On a periodic \(L \times L \times L\) torus, the crystal momentum takes values \(\mathbf{k} = 2\pi \mathbf{n}/L\) with \(\mathbf{n} \in \{0, 1, \ldots, L-1\}^3\). The lattice Fourier transform:

\[ \tilde{\phi}(\mathbf{k}) = \frac{1}{L^3} \sum_{v} \phi(v) \, e^{-i\mathbf{k} \cdot v} \tag{P.6} \]

The lattice momentum squared: \[ \hat{k}^2 = 4 \sum_{\mu=1}^3 \sin^2(k_\mu/2) = 2\sum_\mu (1 - \cos k_\mu) \tag{P.7} \]

This is the eigenvalue of \(-\nabla^2\) on the SC stencil.

2.3 P.2.3 The Gamma function

The Euler Gamma function \(\Gamma(s) = \int_0^\infty t^{s-1} e^{-t} \, dt\) for \(\text{Re}(s) > 0\). Special values used:

Argument Value Appears in
\(\Gamma(1/4)\) 3.62561… \(G^*\), Watson identity, CM curve periods
\(\Gamma(1/2) = \sqrt{\pi}\) 1.77245… \(G^*\) denominator
\(\Gamma(3/4) = \pi\sqrt{2}/\Gamma(1/4)\) 1.22542… Euler reflection

Euler reflection formula: \[ \Gamma(s)\,\Gamma(1-s) = \frac{\pi}{\sin(\pi s)} \tag{P.8} \]

At \(s = 1/4\): \(\Gamma(1/4)\,\Gamma(3/4) = \pi\sqrt{2}\).

Chowla-Selberg formula (for CM elliptic curves): expresses the periods of a CM curve in terms of Gamma values at rational arguments. For the curve \(E_i: y^2 = x^3 - x\) with CM by \(\mathbb{Z}[i]\):

\[ \omega_1 = \frac{\Gamma(1/4)^2}{2\sqrt{2\pi}} = \varpi \quad (\text{lemniscate constant}) \tag{P.9} \]

2.4 P.2.4 Elliptic curves and complex multiplication

An elliptic curve over \(\mathbb{Q}\) is a smooth projective curve of genus 1 with a rational point. In Weierstrass form: \(E: y^2 = x^3 + ax + b\) with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).

The \(j\)-invariant: \(j(E) = -1728 \cdot (4a)^3 / \Delta\).

An elliptic curve has complex multiplication (CM) by an imaginary quadratic order \(\mathcal{O}\) if \(\text{End}(E) \cong \mathcal{O}\), rather than \(\text{End}(E) \cong \mathbb{Z}\) (the generic case).

The CM curve relevant to FTD: \[ E_i: y^2 = x^3 - x, \quad j = 1728, \quad \text{End}(E_i) \cong \mathbb{Z}[i] \tag{P.10} \]

Automorphism group: \(\text{Aut}(E_i) = \{1, -1, i, -i\} \cong \mathbb{Z}_4\). Order 4. Square: 16.

2.5 P.2.5 Watson integrals

Watson (1939) computed three triple integrals, one for each cubic Bravais lattice. The one relevant to FTD is the BCC integral:

\[ I_{\text{BCC}} = \frac{1}{\pi^3} \int_0^\pi \!\! \int_0^\pi \!\! \int_0^\pi \frac{dk_1 \, dk_2 \, dk_3}{1 - \cos k_1 \cos k_2 \cos k_3} = \frac{\Gamma(1/4)^4}{4\pi^3} \tag{P.11} \]

The key identity: \[ \frac{\Gamma(1/4)^4}{4\pi^3} = \frac{G^{*2}}{2\pi} \tag{P.12} \]

connecting the BCC Green’s function to the bridge constant.
