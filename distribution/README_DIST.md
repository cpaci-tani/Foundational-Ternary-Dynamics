# FTD v1.0 Distribution Package

Welcome to the **Foundational Ternary Dynamics (FTD)** framework release 1.0. This package is the unified scientific product of the FTD project.

## Package Structure

- **START_HERE.html**: The master dashboard and entry point.
- **manuscript/**: The source for the interactive book (Quarto).
- **dissemination/notebooks/**: The "Toy Universe" and "Genesis to Atoms" laboratory environments.
- **dissemination/visuals/**: Scientific animations (Manim) and Genesis event recordings.
- **certification/**: Formal audit reports and the v1.0 Certification of Maturity.
- **ternary_matrix/**: The core Python physics engine.

## Getting Started

1. Open `START_HERE.html` in any modern web browser.
2. For interactive simulations, install the dependencies: `pip install -r requirements.txt`.
3. To view or modify the manuscript, navigate to the `manuscript/` directory.
