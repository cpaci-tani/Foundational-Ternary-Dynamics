# Legacy Root Visualization Scripts

These one-off plotting and animation helpers were relocated from the repository
root on 2026-06-18 during cleanup. They are preserved for provenance and possible
reuse, but they are not part of the canonical proof or verification surface.

Most scripts write outputs to a local Antigravity/Gemini artifact directory rather
than a tracked project output directory. Treat generated media as local-only unless
a publication or audit explicitly cites it.
